# 升级手册 —— V4.4.6（跟进表新增「时间差」计算列）

> 适用：已用 /pm 部署在 Ubuntu 服务器（nginx:80 → app 127.0.0.1:8080，systemd，`/opt/pmplatform`，venv `/opt/pmplatform/.venv`）。
> 本次**前后端都有改动**：后端 `followup_columns.py` / `server.py`，前端 `dist`。
> 随附最小更新包：`pmplatform-update-V4.4.6.zip`。

---

## 0. 本次加了什么

四张跟进表——**临时重点跟进 / 风险跟进 / 回款重点跟进 / 重点商机跟进**——的「列设置」里，
超管可以新建第三种列：**时间差**。它自动计算「**指定日期 − 指定列**」的天数。

- **指定日期**三选一：当前日期 / 某个固定日期 / 另一个日期列
- **指定列**：该表的任一日期列（含 V4.4.4 新增的计划关闭时间、实际关闭时间、原项目立项日期等）
- 结果按**天**显示，正数表示指定日期更晚

**典型用法**：新建一列「立项至今天数」= 当前日期 − 立项日期。

> ### 三点要知道
>
> **① 它是算出来的，不能填写。** 其他管理员看得到、能排序、能导出，但**不能编辑**；也没有
> 「归档清空」选项——本来就没有值可清。后台已封死对该列的写入。
>
> **② 归档历史视图里按「当前日期」计算。** 例如「立项至今天数」，在历史归档里看到的是
> 「到今天为止」的天数，**不是**「到归档当时」的天数。看历史数据时请注意这一点。
>
> **③ 被引用的列如果删掉或改名，该列会显示 `-`。** 为便于核对，列设置里每一行都会显示
> 它的引用关系（如「今天 − 立项日期」）。
>
> **④ 本次无需点「更新数据」。** 既有的自定义列与已填数据零影响。

| 内容 | 需更新数据? |
|---|---|
| 新增时间差列类型 | **否**（配置类功能，不进数据管线） |

## 1. 升级步骤（Ubuntu，约 3 分钟）

```bash
# 0) 上传并解压
cd /tmp && unzip -o pmplatform-update-V4.4.6.zip

# 1) 备份 dist 与后端
TS=$(date +%Y%m%d-%H%M)
sudo cp -r /opt/pmplatform/frontend/dist /opt/pmplatform/frontend/dist.bak-$TS
sudo cp /opt/pmplatform/server.py /opt/pmplatform/server.py.bak-$TS
sudo cp /opt/pmplatform/followup_columns.py /opt/pmplatform/followup_columns.py.bak-$TS

# 2) 覆盖后端（本次后端有改动，必须覆盖）
cd /tmp/pmplatform-update-V4.4.6
sudo cp -f *.py /opt/pmplatform/

# 3) 覆盖前端 dist
sudo rm -rf /opt/pmplatform/frontend/dist
sudo cp -r frontend/dist /opt/pmplatform/frontend/dist

# 4) 重启后端
sudo systemctl restart pmplatform
sudo systemctl status pmplatform --no-pager | head -5

# 5) 浏览器 Ctrl+F5 硬刷 /pm,左上角版本号应为 V4.4.6
```

## 2. 升级后验证清单

- [ ] 左上角版本号 **V4.4.6**
- [ ] 四张跟进表各打开「列设置」→ 新建列的类型下拉里出现**「时间差」**
- [ ] 选「时间差」后出现两个下拉：**指定日期**（当前日期/指定日期/选择列）与**指定列**
- [ ] 「指定列」下拉里是该表的日期列。风险跟进页显示的是中文列名（「立项日期」「计划关闭时间」等）；**不应**出现「项目名称」这类非日期列
- [ ] 新建一列「立项至今天数」（当前日期 − 立项日期）→ 表格出现该列、数值合理、右对齐、**可点列头排序**、导出的 xlsx 里是**数字**
- [ ] 该列单元格**不可编辑**（无输入框/日期选择器）；列头**无筛选入口**
- [ ] 找一条**从未填过任何跟进**的记录 → 该行的时间差列**同样有值**
- [ ] 找一个没有立项日期的项目 → 该行显示 `-`，页面不报错
- [ ] 列设置里该行显示引用关系「今天 − 立项日期」；改列名后数值不变
- [ ] 删除该列 → 提示「清除 0 行值」（计算列本就没有存储值）
- [ ] 既有的文本/日期自定义列与其中已填数据**完全不受影响**

## 3. 回滚

```bash
TS=<你升级时用的时间戳>
sudo rm -rf /opt/pmplatform/frontend/dist
sudo mv /opt/pmplatform/frontend/dist.bak-$TS /opt/pmplatform/frontend/dist
sudo cp -f /opt/pmplatform/server.py.bak-$TS /opt/pmplatform/server.py
sudo cp -f /opt/pmplatform/followup_columns.py.bak-$TS /opt/pmplatform/followup_columns.py
sudo systemctl restart pmplatform
```

> `data/`/`input/` 不受影响。若回滚前已建过时间差列，回滚后该列配置仍在
> `data/followup_columns.json` 里但旧版不认识它，会被旧版的配置读取逻辑忽略——
> 不影响其他列，如需彻底清除可在回滚后手工编辑该文件删掉对应条目。
